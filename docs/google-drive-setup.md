# Googleドライブに保存するための準備（最初に一度だけ）

世界をGoogleドライブに保存すると、PCとスマホの両方で同じ世界を開けます。
そのために、Google に「このアプリがドライブを使います」と届け出て、**クライアント ID**（アプリの名札のような長い文字列）をもらいます。
無料です。お金の登録（請求先アカウント）は要りません。15分ほどかかります。

> 画面の文字は、Google がときどき変えます。ボタンの名前が少し違っても、だいたい同じ場所にあります。
> 英語で表示されたときは、括弧の中の英語を目印にしてください。

先に、アプリを GitHub Pages で公開しておいてください（このページの一番下「アプリの公開」）。

---

## 1. Google Cloud を開く

1. PCで https://console.cloud.google.com/ を開きます。
2. **ドライブに保存したい Google アカウント**でログインします。
3. 初めてなら、利用規約の画面が出ます。国を「日本」にして、同意して進みます。

## 2. プロジェクトを作る

1. 画面の左上、「Google Cloud」の文字の右にあるボタン（プロジェクトの選択）を押します。
2. 出てきた窓の右上の **「新しいプロジェクト」（New project）** を押します。
3. プロジェクト名に `TRPG` と入れて、**「作成」（Create）** を押します。
4. 少し待つと右上にお知らせが出ます。**「プロジェクトを選択」（Select project）** を押します。
   左上のボタンに `TRPG` と出ていれば大丈夫です。

## 3. Google Drive API を使えるようにする

1. https://console.cloud.google.com/apis/library/drive.googleapis.com を開きます。
   （左上が `TRPG` になっていることを確かめてください）
2. 青い **「有効にする」（Enable）** を押します。

## 4. 同意画面を作る（ログインのときに出る画面）

1. https://console.cloud.google.com/auth/overview を開きます。
2. **「開始」（Get started）** を押します。
3. 順に入れていきます。
   - **アプリ名**（App name）：`TRPG 世界設定`
   - **ユーザー サポートメール**（User support email）：自分のメールアドレスを選ぶ
   - 「次へ」
   - **対象**（Audience）：**外部**（External）を選ぶ → 「次へ」
   - **連絡先情報**（Contact information）：自分のメールアドレス → 「次へ」
   - 同意のチェックを入れて → 「続行」 → **「作成」（Create）**
4. 左の列の **「対象」（Audience）** を押します。
5. 下の方の **「テストユーザー」（Test users）** の **「＋ ユーザーを追加」（Add users）** を押して、
   **ドライブに保存したい Google アカウントのメールアドレス**を入れ、「保存」を押します。

「公開ステータス：テスト中」（Testing）のままで大丈夫です。テストユーザーに入れた人だけが使えます。
（「アプリを公開」は押さないでください。押すと Google の審査が要るようになります）

## 5. クライアント ID を作る

1. https://console.cloud.google.com/auth/clients を開きます。
2. **「クライアントを作成」（Create client）** を押します。
3. 入れていきます。
   - **アプリケーションの種類**（Application type）：**ウェブ アプリケーション**（Web application）
   - **名前**：`TRPG 世界設定`（何でも構いません）
   - **承認済みの JavaScript 生成元**（Authorized JavaScript origins）の **「＋ URI を追加」** を押して、次を入れます：

     ```
     https://bojo2803-rgb.github.io
     ```

     最後に `/` や `/TRPG` を**付けないで**ください。
   - 「承認済みのリダイレクト URI」は空のままにします。
4. **「作成」（Create）** を押します。
5. 出てきた窓の **クライアント ID**（`123456789012-abcdefg….apps.googleusercontent.com` の形）の横のコピーのボタンを押します。
   - 「クライアント シークレット」は使いません。人に見せる必要もありません。
   - あとで見るときは、同じ https://console.cloud.google.com/auth/clients の一覧から名前を押すと出ます。

> 作ってすぐは「つなぐ」がうまくいかないことがあります（Google 側の準備に数分〜数時間かかることがあります）。そのときは少し待ってからやり直してください。

## 6. アプリに貼って、つなぐ

1. アプリ（https://bojo2803-rgb.github.io/TRPG/ ）を開きます。
2. 右上の **⚙（設定）** を押し、下の方の **「Googleドライブ」** の欄に、コピーしたクライアント ID を貼ります。
3. **「つなぐ」** を押します。Google のログインの窓が出ます。
   - アカウントを選びます。
   - 「Google はこのアプリを確認していません」と出たら、**「続行」**（または「詳細」→「TRPG 世界設定（安全ではないページ）に移動」）を押します。
     自分で作ったアプリなので大丈夫です。
   - 「このアプリで使用する Google ドライブのファイルの表示、編集…」に **チェックを入れて**、「続行」を押します。
4. 設定の画面に「つながりました」と出れば完了です。
5. いまの世界をドライブに置くときは **「いまの世界をドライブに写す」** を押します。
   ドライブに「TRPG 世界設定」フォルダができ、その中に世界ごとのフォルダができます。

このアプリが読み書きできるのは、**このアプリが作ったファイルだけ**です。ドライブのほかのファイルは見えません。

## 7. スマホでも使う

1. PCのアプリの設定で **「スマホ用のリンクをコピー」** を押します。
2. そのリンクを、メモやメッセージ（LINE の自分だけのトークなど）でスマホに送って、スマホのブラウザで開きます。
   クライアント ID が自動で入ります。
3. 設定（⚙）→「Googleドライブ」→ **「つなぐ」** を押し、6. と同じようにログインします。
4. 左上の世界の名前のボタンを押すと、ドライブの世界が一覧に出ます。

## 8. シナリオの共有リンクのための API キー（共有を使うときだけ）

シナリオの「共有リンク」は、リンクを開いた人が、ログインせずにあなたのドライブの共有ファイルを読めるようにするものです。そのために「API キー」を1つ作ります。

1. https://console.cloud.google.com/apis/credentials を開きます（左上が `TRPG` になっていることを確かめてください）。
2. 上の **「＋ 認証情報を作成」（Create credentials）** →  **「API キー」（API key）** を押します。
3. できたキー（`AIza…` で始まる文字）が出ます。**「キーを編集」（Edit API key）** または一覧のキーの名前を押して、制限を付けます。
   - **アプリケーションの制限**（Application restrictions）：**ウェブサイト**（Websites）を選び、**「＋ 追加」** で次を入れます：

     ```
     https://bojo2803-rgb.github.io/*
     ```

   - **API の制限**（API restrictions）：**キーを制限**（Restrict key）を選び、**Google Drive API** だけにチェックを入れます。
   - **「保存」（Save）** を押します。
4. キーをコピーし、アプリの **⚙（設定）→「Googleドライブ」→「API キー」** に貼ります。

このキーは共有リンクの中に入り、リンクを受け取った人にも見えます。上の制限を付けておけば、このアプリのページから、共有したファイルを読むことにしか使えません。

使い方：シナリオを開き、詳しい画面の **「共有」→「共有リンクを作る」**。出てきた「リンクをコピー」で、URLを相手に送ります。中身を直したら **「更新」**（URLは同じまま）、やめるときは **「共有をやめる」**。

## うまくいかないとき

| 出てくる文字 | すること |
|---|---|
| `アクセスをブロック：…はテスト中で…`、`403: access_denied` | 4. の 5 で、そのメールアドレスをテストユーザーに入れたか確かめる |
| `Error 400: redirect_uri_mismatch`、`origin_mismatch`、`idpiframe_initialization_failed` | 5. の生成元が `https://bojo2803-rgb.github.io` ちょうどか確かめる（最後に `/` なし）。直したあと数分待つ |
| `Googleにつなげませんでした（popup_closed）` | ログインの窓を閉じてしまった。もう一度「つなぐ」 |
| ポップアップがブロックされた | ブラウザのアドレス欄のポップアップのしるしから、このサイトを許可する |
| 上に「保存できませんでした」と「つなぎ直して保存」 | ボタンを押す（ログインが1時間ほどで切れるため。押すと続きを保存します） |
| `Google Drive API has not been used in project…` | 3. をやり直す（左上のプロジェクトが `TRPG` か確かめる） |
| 共有リンクを開くと「読み込めませんでした（403）」 | 8. の API キーの制限（ウェブサイトの欄と、Google Drive API）を確かめる。直したあと数分待つ |
| 共有リンクを開くと「共有がやめられたか、リンクがまちがっています」 | 共有した人が「共有をやめる」を押したか、ファイルを消した。もう一度「共有リンクを作る」 |

## アプリの公開（GitHub Pages）

アプリをインターネットに置く手順です。最初に一度だけ。

1. https://github.com/bojo2803-rgb/TRPG/settings/pages を開きます。
2. **Build and deployment** の **Source** を **「GitHub Actions」** にします。
3. https://github.com/bojo2803-rgb/TRPG/actions を開き、左の「アプリを公開」→ 右の **「Run workflow」** → 緑の **「Run workflow」** を押します。
4. 1〜2分で緑のチェックが付きます。https://bojo2803-rgb.github.io/TRPG/ でアプリが開きます。

以後は、アプリが直されるたびに自動で公開し直されます。

リポジトリを公開（Public）にしている間は、プログラムは誰でも見られます。
**世界のデータはプログラムには入っていない**ので、見られることはありません（データはあなたのブラウザの中か、あなたのGoogleドライブにだけあります）。
