# 要素と軽い付箋 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn notes into typed cards (note/person/scenario/item/group) with element tabs and own boards, a quick note input, scenario clouds on the time map, and imageless maps with pin lines.

**Architecture:** One `notes` collection gains `kind`. Element tabs are one generic list/open view (`kindView.js`) that embeds the existing board. Period relations are links with `from`/`to`. The time-map engine gets a `cloud` scene element. Maps gain pin ids and `lines`.

**Tech Stack:** Static ES modules, no build; node:test for units; Playwright e2e (`tests/e2e/*.mjs`).

**Spec:** `docs/superpowers/specs/2026-10-01-elements-design.md`

## Global Constraints

- No world data in program files; samples stay in `app/examples/` (regenerate with `node tools/make-examples.mjs`).
- UI text Japanese only. Phone width 390px: no horizontal page overflow.
- World format `trpg-world`, VERSION becomes 2; v1 worlds and prototype exports must still open.
- Commits end with the session's attribution lines; push only to `claude/happy-fermat-d43t9j`.

## Review Focus

- A v1 world opened in v2: every note gets a kind, nothing disappears, templates not duplicated on re-migration.
- Deleting a pin or a note removes its map lines; merge cleanup does the same.
- Element board navigation: back works after several hops and after the element is deleted (falls back to list).
- Quick input: Enter with an empty box creates nothing; Shift+Enter makes a newline.
- Time map clouds: no cloud for collapsed scenarios; switching views in all examples never throws.
