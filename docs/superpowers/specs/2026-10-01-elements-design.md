## 2. しくみ（案A：種類の違うカード）

- 付箋・人物・シナリオ・アイテム・集団は、すべて同じ「カード」（データでは今の付箋 `notes`）。違いは `kind`（`note`・`person`・`scenario`・`item`・`group`）だけ
- 付箋以外をまとめて「要素」と呼ぶ。要素は自分のボード（`boards` の `owner`）を持つ
- どの種類も、ボードに貼る・線でつなぐ・時系列や地図に置く・グラフに出る、が今までどおりできる
- 種類はあとから変えられる（付箋 → 人物 など）

## 3. 付箋（軽くする）

- 付箋タブの一番上に入力欄。1行目が題名、2行目からが本文。Enter で1枚（Shift+Enter で改行）。作った付箋はどこにも貼られない（「どこにも貼っていない」で見られる）
- 上の「＋ 付箋」とキーボードの N：同じ入力欄を小さな窓で出す。ボード（要素のボードを含む）を見ているときは、そのボードの見ている所に貼る
- ボードのバーにも同じ入力欄（書いて Enter でそのボードに貼る）
- 付箋の編集画面：題名・色・タグ・本文・貼ってあるボード。時系列・まとめ・つながり・家族は、使っているときだけ出す。「もっと」で全部出す
- 付箋の一覧：付箋（種類 `note`）だけ。カードに、貼ってある要素の名前が出る。「どこにも貼っていない」で絞れる
- 編集画面のメニュー：「人物にする」「シナリオにする」「アイテムにする」「集団にする」（要素なら「付箋に戻す」とほかの種類）

## 4. 要素

### 4.1 共通

- タブ：付箋・人物・シナリオ・アイテム・集団・ボード・時系列・地図・グラフ・テンプレート（家系図は人物タブの中へ）
- 各タブは一覧（カードの並び。タグで絞る・並べ替え・検索）。上の「＋ 人物」などで名前を入れて作る
- 要素を開く：画面の大部分にその要素のボード（初めて開いたときに作る。真ん中に要素自身のカード）、右に詳しい画面。スマホでは詳しい画面は「詳しく」で開く
- ボードの上の要素のカードを押すと、その要素のボードへ移る。上の「← 戻る」で前の画面へ（何回でも戻れる）
- 決まった欄は、種類ごとのテンプレート（テンプレートに「この種類に出す」を足す）。最初から用意するもの：

| 種類 | 欄 |
|---|---|
| 人物 | よみ・性別・年齢・職業・外見・性格・口調・経歴 |
| シナリオ | 状態（準備中／完成／遊んだ）・人数・遊ぶ時間・概要・導入・ハンドアウト・真相・結末 |
| アイテム | 区分（キーアイテム／アーティファクト／そのほか）・見た目・効果・由来・代償 |
| 集団 | 種類・目的・規模・資金・拠点・雰囲気 |

- CoC 6版のシートは今までどおり、タグ「探索者」「NPC」で出る

### 4.2 人物

- 詳しい画面：欄・タグ・メモ（本文）・所属・持ち物・登場するシナリオ・家族・時系列（主体の道筋）・つながり・出てくるところ
- 所属：集団と役職、入った時・抜けた時（どちらも空でよい）。集団の画面のメンバーと同じもの
- 持ち物：アイテムの持ち主の移り変わりのうち、この人物のもの（期間つき）
- タブの中で「一覧／家系図」を切り替える

### 4.3 シナリオ

- 詳しい画面：欄・メモ・出来事（中身のうち時系列にあるもの。時間順）・登場（中身の人物・アイテム・集団）・遊んだ記録・つながり・出てくるところ
- 中身は今の「まとめ」（`parents`）。シナリオの中に出来事・人物・アイテム・集団を入れる。1つのカードを2つ以上のシナリオに入れてもよい
- 遊んだ記録：日付・参加者・メモを何回分でも（`sessions`）
- 一覧は「状態」で絞れる

### 4.4 アイテム

- 詳しい画面：欄・メモ・持ち主の移り変わり（時間順）・登場するシナリオ・つながり・出てくるところ
- 「持ち主を変える」：新しい持ち主（人物・集団・ほかのカード）、いつから（暦の入力。わからなければ空）、どうやって（盗んだ・譲られた…）。前の持ち主の期間はそこで終わる。日時があれば、時系列の本線に「〇〇が△△の手に渡る」の出来事（付箋）も置ける（初めから入）
- 一覧は「区分」で絞れる

### 4.5 集団

- 詳しい画面：欄・メモ・メンバー（役職・入った時・抜けた時）・上部組織と下部組織（集団どうしのまとめ）・つながり（同盟・敵対などはつながりのラベル）・出てくるところ
- タブの中で「一覧／組織図／相関図」
  - 組織図：上部組織から下部組織へ木の形に並べ、各集団の下にメンバー（役職）を出す
  - 相関図：集団どうしのつながりを網の目で（ラベルつき）

### 4.6 期間つきのつながり（データ）

- 所属：つながり `kind: 'member'`（a＝人物、b＝集団、`label`＝役職、`from`・`to`＝日時）
- 持ち主：つながり `kind: 'holds'`（a＝持ち主、b＝アイテム、`label`＝どうやって、`from`・`to`）
- `from`・`to` の形は出来事の日時と同じ（`{ tr, t, prec, tz, approx?, until? }`）。空なら null
- ボード・グラフでは、ふつうのつながりと同じように線で出る（ラベルは役職など）

## 5. 時系列のシナリオ（もや）

- 出来事の「シナリオ」＝その出来事の親のうち最初のシナリオ（なければ最初の親）
- ひらいているシナリオ：その出来事の付箋を、世界線の破片ごとに、雲の形のもやで覆う。もやの左上にシナリオ名（押すとたたむ）。色はシナリオのカードの色
- もやは名前（シナリオ・世界線・何番目の破片）で突き合わせ、視点の切り替えのあいだは、前後のもやの四角を混ぜて動かす
- たたんだシナリオ：今までどおり1枚の付箋「▸ 名前」
- 「＋ シナリオ」（時系列のバー）：名前と、入れる出来事（世界線ごと・時間順のチェック）を選んで作る
- 出来事の編集画面の「シナリオ」欄：入っているシナリオ（外す）と「＋ シナリオに入れる」

## 6. 地図

- 「＋ 地図」で「画像」か「画像なし（方眼の紙）」を選ぶ。画像なしは横2000×縦1400の方眼
- ピンどうしを線で結ぶ：ピンのメニューの「ここから線を引く」→ 相手のピンを押す。線を押すとラベル・色・線の種類・削除
- 画像ありの地図でも同じ
- データ：ピンに `id` を付ける。線は `lines: [{ id, a: ピンid, b: ピンid, label, color, style }]`。ピンを外すと、そのピンの線も消える

## 7. いまのデータの引き継ぎ（世界の版 1 → 2）

- タグ「探索者」「NPC」「人物」のカードと、時系列の主体 → 人物
- タグ「シナリオ」のカード → シナリオ
- それ以外 → 付箋
- 種類ごとのテンプレートを足す。地図のピンに id、`lines: []`
- 試作品の書き出しを読み込むときも同じ（まとめ → シナリオ）

## 8. しないこと（今回）

- 時系列のもやは、1つの出来事につき1つ（最初のシナリオ）
- 要素ごとの「その時点で持っている物・所属」の自動の絞り込み（期間は文字で出すだけ）
- 場所（ロケーション）のタブ（場所は付箋か要素で表し、地図のピンにする）
- 地図に図形や文字を描くこと（回答どおり、ピンと線だけ）

## 9. 確かめ方

- 単体：引き継ぎ（版1の世界 → 種類・テンプレート・ピンid）、種類を変える、ピンを外すと線が消える、合わせ方（kind・lines を含む）
- ブラウザ：付箋の入力欄で1枚・ボードの入力欄で貼る、人物を作って開く→ボード→付箋を貼る→戻る、所属・持ち主を変える（出来事ができる）、シナリオを作って時系列にもや（見本すべての視点の切り替えで、もやが飛ばない）、画像なしの地図・線、スマホの幅で全部のタブ
