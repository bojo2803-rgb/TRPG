# 時系列マップ試作品（第6版）：作例の物語と、使ってみて見つけた問題

- 目的：複雑なタイムトラベルの物語を、試作品の**画面の操作だけで**図にしてみて、操作のしやすさ・わかりやすさの問題をすべて洗い出す
- 作った物語は、試作品の「見本を開く」から開ける（いまの世界と入れ替わる。「元に戻す」で戻せる）
- 関連：設計メモ §10（試作品の経過）

## 2. 作りながら見つけて、直したもの（第6版に反映済み）

1. **白紙から始められなかった**。新しい物語を作るには、サンプルを1つずつ消すしかなかった → 「見本を開く」に「白紙（本線だけ）」と作例の物語を入れた
2. 主体を足すと視点がその主体に移るのに、映し直さないので、新しい線が画面の端に小さく出ていた → 主体が変わったら映し直す
3. 付箋や世界線を足しても、画面の外だと足されたことに気づけなかった → 足したものが画面の外なら、そこまで横に動かす
4. 本線の範囲を変えると線が画面の一部に縮み、「＋ つなぐ」でクリックしても焦点の横線に当たって何も起きなかった → 横線はクリックを受けない。編集で線が細くなりすぎたら映し直す
5. 視点が動いている途中にクリックすると、ずれた日時（例：2100年）で受け付けていた → 押した時点で動きを終わらせてから受け付ける
6. 架空の暦の名前を入れてから日付の欄をクリックすると、入力が暦の名前に入ってしまった（「角度の刻111」）→ 暦の名前を変えても日付の欄を作り直さない
7. **「〜年前」の日時を持つ主体は、開いて何も変えずに保存するとエラーになった**（表示を4桁に丸めていたため）→ 開いたときと同じ日時なら元の値のまま保存する。丸めずに表示する
8. 分岐した世界線の、主体が来る前の部分が分岐点と細い点線でしかつながらなかった → そこも斜めの線で分かれる
9. 分岐元が横にずれた所にあるとき、斜めの線が長い横線＋急な斜めになって、分岐がどこからか誤解しやすかった。生まれる前の時代へ行く主体（旅人ソラ）でも、残りの破片が遠い切れ目へ長い斜め線を引いていた → 行き先がすぐ横にあるときだけ斜めにし、遠いときは細い点線で結ぶ
10. ループの何周目かが画面でわからなかった → ループの折り返し（○）に「3周目へ」と出す
11. 見本を開いた直後に「元に戻す」と、描画が壊れることがあった → 別の世界への切り替えでは動かさずに切り替える
12. 一覧で、移動の到着側の説明が逆向きに読めた（「γ世界線 → 移動」）→ 「移動：γ世界線から」
13. **付箋が重なりすぎた所では、5枚目以降が何も言わずに消えていた**（サンプルの客観の視点で「観測者O 誕生」など3枚、物語2の村人タロウの視点で5枚）→ 「＋3」のようにまとめて出す。カーソルで名前、クリックでそのあたりを拡大

直したものは自動確認に加えた（開いて保存しただけではデータが変わらないこと、見本の世界すべての配置の決まり、暦の名前の入力、見本を開いてすぐ元に戻すこと）。

## 3. まだ残っている問題

### 高：入力の手間とデータの表し方

1. **主体の区間の入力が重い**。区間ごとに世界線・入った日時（年・月・日・時刻）・出た日時・移り方の名前を入れる。前の区間の「出た」と次の区間の「入った」はほとんど同じ日時なのに、世界線を変えると毎回入れ直しになる（岡部で67回）
2. **世界線を選び直すと、日時の欄がその世界線の始まりに戻る**。先に日時を入れてから世界線を選ぶと消える（付箋・主体・ループのどの画面も）。同じ時計の世界線どうしなら、日時はそのまま残してよいはず
3. **分岐の前は同じ人物**を、世界線ごとに別の主体として作ると、分岐前の人生を2回入れることになる（まゆり（α）と（β））。「分岐で2人に分かれる人物」を1回で作る方法がない
4. **意識だけの移動**（タイムリープ、イスの種族との入れ替わり、遼丹）を表せない。体ごとの移動と同じ扱いになり、タイムリープは「自分が重なる（2人いる）」と表示される。体と心を別の主体に分けると、入力が倍になる
5. **ループの周回ごとに違う出来事**（3周目だけ花火が上がらない）を書けない。ループの中の付箋は、すべての周に同じものが出る
6. **ループの中のループ**（七夜祭の最終夜だけ、さらに3回くり返す）は作れない。重なるループは保存を断る
7. 閉じたループ（輪）の中の付箋は同じ位置に積み重なり、拡大しても分かれない（「＋1」が残る）
8. 保存はこのブラウザの中だけ。別の端末では見られず、書き出し・読み込みもない（本体ではGoogleドライブ）。「元に戻す」も再読み込みで消え、やり直し（Ctrl+Y）はない

### 中：見やすさ

9. 往復の多い主体（騎士アルト）や、生まれる前の時代へ行く主体（旅人ソラ）の視点では、残りの破片・斜めの線・点線が増えて読みにくい
10. 客観の視点で、同じ時期へ跳ぶ移動がいくつもあると、点線と「≈1.5億年前へ」の文字が重なる（物語4）
11. 焦点の線を画面の縦の真ん中に置く決まりのため、上下の世界線が多いと画面から出る。「全体」も横しか合わせない
12. ループの周回の破片・重なりの破片の名前（「3周目」「重なり」）は、幅が足りないと出ない（カーソルを合わせると出る）
13. 竜宮のように短い世界線は、客観の視点では細く、付箋が上に高く積み上がる
14. スマホでは地図の部分が狭く、付箋と文字が重なりやすい。付箋を引っぱると「延ばす」操作になるので、付箋が密な所では地図を動かしにくい
15. 世界線の色は作った順に6色をくり返し、選べない。7本目から同じ色になる
16. 世界線の上下の並びは「本線の上／下」しか選べない

### 低：あると助かる機能

17. まとめ（シナリオ）の名前の変更・削除ができない（付箋の画面から作るだけ）
18. 時間の外の世界（ティンダロス）にも、架空の暦（年・月・日）を持たせるしかない
19. 架空の暦は「1年＝12か月×30日」だけ。「〜年前」の入力もない
20. 「1.5億年前から5年間」のような「始まり＋長さ」の入れ方がなく、「149999995年前」と打つしかない
21. 検索は付箋を光らせるだけで、その場所へ動かない
22. 主体の区間の並べ替え・途中への挿入ができない（削除して足し直す）。つなぐ操作の「主体がここから移る」は途中に挿入できるが、そのあとの区間はずれない
23. 主体が多いと、視点の切り替えボタンが何行にもなる
24. 時計を比べられない世界どうし（夢など）の移り方は、いつも「移動」と判定する。夢の中で過去の夢へ入る、のような場合は自分で「タイムトラベル」に直す必要がある
25. ループの回数の上限は99周（周回ごとに線を描くため）

## 4. 次に直すなら（提案）

- まず 1・2（区間の入力）：次の区間の「入った」を前の区間の「出た」から埋める。同じ時計の世界線に選び直しても日時を残す。地図の上で区間をなぞって作る操作も検討する
- 3・4（分岐する人物・意識だけの移動）は、本体のデータの形を決める前に方針を決めたい
  - 案：主体に「分岐で分かれる」印を付けると、分岐点で自動的に2人になる
  - 案：移り方に「体ごと／意識だけ」を選ぶ欄。意識だけのときは「重なり」ではなく「上書き」として描く
- 5・6（周回ごとの出来事、入れ子のループ）は、付箋に「何周目」を持たせる形と、ループを世界線の一種にする形を比べて決めたい
