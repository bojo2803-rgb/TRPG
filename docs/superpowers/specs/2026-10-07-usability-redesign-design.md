# 使いやすさの作り直し — 設計

- 作成：2026-10-07。要望「なんとなく使いにくい。見直して考察し、ヒアリングで正体を特定し、改善案を考えて」と、その回答をまとめた
- 進め方：「全部まとめて作る」「大きく作り直してよい（入れたデータはそのまま）」

## 0. ヒアリングでわかったこと

| 聞いたこと | 答え |
|---|---|
| 困る瞬間 | 探したいものが見つからない。タブの行き来がやりにくい（1つのアイデアで複数の項目に入れるとき、切り替えが多い） |
| 使う場面 | セッションの準備・世界の設定づくり・思いつきのメモ・セッション中に見返す（全部） |
| 人物を押したら | その人の情報（プロフィール） |
| 端末 | ほぼパソコン |
| 切り替えが要るとき | 人物・出来事・シナリオ・場所／組織、どれを作るときも |
| 面倒な点 | 元の画面に戻るのが大変。相手を先に作りに行く |
| 探しにくさ | 一覧から目で探すのが大変 |
| 人物の数 | 100人より多い |
| あまり使わないタブ | ボード・時系列（消さないこと。これから使うかもしれない） |
| 一覧に欲しいもの | 絵・まとまりごと・表 |
| 追加の要望 | 複数選んでまとめて操作したい。文脈で候補を絞ってほしい（例：シナリオのチャートで、登場しない人物を足せてしまう） |
| まとめてしたいこと | シナリオに入れる・外す、場所を移す、所属・タグを付ける、消す（全部） |
| シナリオの外の人物 | 出さない。「ほかから選ぶ」で広げると、そのシナリオの登場にも入る |
| ほかに絞りたい所 | 一覧をシナリオで絞る・検索でいまのシナリオを先に・家系図と相関図もシナリオで |

**正体**：
1. 考えは「話」でつながるのに、画面は「種類」で分かれていて、「行って、作って、戻る」が操作の大半になっている（ブラウザの「戻る」も効かない）
2. 100人以上を、名前だけの同じ見た目のカードで探している
3. 開いた先が、求めているもの（情報）でなく、空のボードと細長い入力画面

## 1. 画面の骨組み

```
┌ 上：世界の名前・保存の状態 ・［どこからでも探す］・＋付箋・元に戻す・やり直す・設定 ┐
├ 左 ─────────┬ 真ん中 ─────────────────────┬ 右（小窓）────┤
│ 人物          │ 一覧（表・カード・まとまり）      │ 重ねて開いた   │
│ シナリオ      │   または                          │ 人物・場所・   │
│ ロケーション  │ ページ（開いた人物などの情報。    │ 付箋など       │
│ 集団          │   ボード・チャート・地図に切替）  │ （道すじつき） │
│ アイテム      │                                   │                │
│ 付箋          │                                   │                │
│ ─ ほかの見方 ─│                                   │                │
│ ボード・時系列│                                   │                │
│ グラフ・テンプレ│                                 │                │
│ ─ 最近 ─      │                                   │                │
│ 最近の10件    │                                   │                │
└───────────────┴───────────────────────────────────┴────────────────┘
```

- 左のタブは、主な6つ（人物・シナリオ・ロケーション・集団・アイテム・付箋）と、「ほかの見方」の4つ（ボード・時系列・グラフ・テンプレート）に分ける。どれも消さない。「ほかの見方」は字を小さく・薄くする
- 左の一番下に「最近」：最近開いたもの10件（新しい順）。押すとそこへ行く
- 右は「小窓」（いまの「詳しい画面」の代わり）。真ん中の画面の上に重ねて開く

### 1.1 重ねて開く方法の選び方（決めたこと）

| 案 | よい点 | 困る点 |
|---|---|---|
| **A 右の小窓に重ねる（採用）** | いまの右の画面を育てるので、慣れた形のまま。真ん中の画面を隠さない | 一度に見えるのは1つ（道すじで行き来する） |
| B 左右に何列も並べる | 2〜3つを見比べられる | 画面が狭くなる。パソコンでも3列が限界 |
| C 浮かぶ窓 | 自由に置ける | 窓が散らかる。スマホで使えない |

## 2. 戻る・進む（ブラウザの「戻る」が効く）

- いまの画面をアドレスの「#」の後ろに書く：`#/people`（人物の一覧）、`#/people/<id>`（人物のページ）、`#/people/<id>/board`（そのボード）、`#/people?sub=family`（家系図）など。画面を移るたびに、ブラウザの履歴に1つ積む
- ブラウザの「戻る」「進む」（マウスの戻るボタン、Alt+←）で、前の画面・ページへ戻れる
- ページの「← 戻る」は、ブラウザの「戻る」と同じ動き。履歴がなければ、その種類の一覧へ
- 読み込み直したときは、アドレスの画面を開く（なければ前回の画面）
- これまでの `#import&…`（共有の取り込み）と `#drive=…`（スマホ用リンク）は今までどおり動く（`#/` で始まらないものは画面の指定とみなさない）
- 小窓の開け閉めは履歴に積まない（小窓は小窓の道すじで戻る）

## 3. どこからでも探す

- 上の検索欄は「探す（人物・場所・シナリオ…）Ctrl+K」。どのタブにいても、**世界のすべて**（人物・シナリオ・ロケーション・集団・アイテム・付箋・出来事）から探す
- 打つと、欄の下に候補が出る（最大30件）。1行ごとに：種類の印・名前・見分ける手がかり（人物なら「職業・所属・いる所」、ロケーションなら道すじ、シナリオなら状態、付箋ならタグ）
- 並び：名前が打った字で始まる → 名前に含む → よみ・欄・タグ・メモに含む の順。同じ順位なら最近開いたもの → 名前順
- ↑↓で選び、Enter で開く（人物などはページ、付箋・出来事は小窓）。Esc で閉じる
- 何も打っていないときは「最近開いたもの」を出す
- Ctrl+K（Mac は ⌘K）と「/」で、どこからでも検索欄へ
- これまで上の欄でしていた「いまの一覧を絞る」は、各一覧の上の「この一覧を絞る」欄に移す（人物・シナリオ・アイテム・集団の一覧、付箋の一覧、ロケーションの木）

## 4. 一覧（100人以上でも探せる）

人物・シナリオ・アイテム・集団の一覧に「表／カード／まとまり」の切り替えを付ける（種類ごとに覚えておく。初めは、人物は表、ほかはカード）。

### 4.1 表
| 種類 | 列 |
|---|---|
| 人物 | 絵・名前・職業・年齢・所属・いる所・登場するシナリオ |
| シナリオ | 名前・状態・人数・舞台・登場の数 |
| アイテム | 名前・区分・いまの持ち主・ある所 |
| 集団 | 名前・種類・人数（いまのメンバー）・拠点（場所） |

- 列の見出しを押すと、その列で並べ替え（もう一度押すと逆順）。空の値はいつも最後
- 行を押すとページを開く
- 職業・年齢・状態などは、テンプレートにその名前の欄があればその値（なければ空）。表の年齢は「年齢」の欄の値だけ（生年月日からの歳はシナリオの時期で変わるので、表では計算しない）
- いる所は道すじの最後の2つ（「新宿 › 喫茶「黄昏」」）

### 4.2 カード
- いまのカードに、絵（左に小さく）と見分ける手がかり（表の列の中身を1行に）を足す
- 「ボードはまだ空」は出さない（ボードに何か貼ってあるときだけ「ボードに3枚」）

### 4.3 まとまり
- 「何でまとめるか」を選ぶ：人物は「所属・シナリオ・いる所」、シナリオは「状態」、アイテムは「持ち主・区分」、集団は「種類」
- まとまりごとに見出し（数つき）とカード。複数の所属がある人は、それぞれに出る。どこにも入らないものは最後の「なし」に

### 4.4 絵
- 人物・シナリオ・アイテム・集団・ロケーションに、絵を1枚付けられる（ページの名前の横の絵の枠を押して選ぶ。付け替え・外すもできる）
- 絵がなければ、メモの中の最初の画像を使う。それもなければ、名前の最初の1文字を色の丸に入れて出す
- 絵は今の画像と同じく、保存先（ブラウザ・ドライブ）に置く

## 5. ページ（開いたら、まず情報）

- 一覧で押す・検索で選ぶ・「ページで開く」で、真ん中にその人物などのページが出る
- 上の行：← 戻る・種類の印・（ロケーションは上の道すじ）・名前・見せ方の切り替え
  - 人物・アイテム・集団：**情報**／ボード
  - シナリオ：**情報**／チャート／ボード
  - ロケーション：**情報**／地図／ボード
  - 切り替えは種類ごとに覚えておく（初めは情報）
- 情報の中身（パソコンの広い画面は2段組）：
  - 左の段：絵・名前・見分ける手がかり、テンプレートの欄、メモ
  - 右の段：つながりの欄（所属・持ち物・いる所・登場するシナリオ・家族・中身・遊んだ記録・共有…）
  - 一番下に「そのほか」：色・タグ・ボード／地図／リンク・削除
- 欄の出し方（長い入力画面をやめる）：
  - 1行の欄（よみ・性別・年齢・職業など）は、空でもいつも出す（小さいので）
  - 何行も書く欄（外見・性格・経歴など）は、書いてあるものだけ出す。空のものは「＋ 外見」「＋ 性格」…のボタンにたたみ、押すとその欄が開いて書ける
- ページを開いても、右の小窓は自動では開かない（同じものを2か所に出さない）
- 見出しの言葉：「つながり」→「ほかとのつながり」、「出てくるところ」→「ボード・地図・リンク」。「まとめ」は付箋だけに出す。「もっと」のボタンは、その種類で使えるものだけを書く（シナリオに「家族」は出さない）

## 6. 小窓（重ねて開く）

- 人物・場所などの名前（札・メモのリンク・表の中の名前など）を押すと、右の小窓に開く。小窓の中身は、ページの情報と同じ（1段組）
- 小窓の中で別の名前を押すと、その上に重なる。上に道すじ「黄昏の喫茶店 › 店主 葛城 › 星の智慧派」。道すじを押すとそこへ戻る。「‹」で1つ戻る、「×」で全部閉じる
- 重ねられるのは8つまで（9つ目を開くと一番下を外す）
- 「ページで開く」：その人物などのページへ移る（小窓は閉じる）。付箋・出来事にはページがないので出さない
- 「大きく」（今ある機能）は小窓にも残す
- 左のタブで別の画面へ移ると、小窓は閉じる（関係のない画面に付いてこない）
- ロケーションの木で選んだときは、小窓をそのロケーションだけにする（いまの「選ぶと詳しい画面も切り替わる」を保つ）。付箋の一覧・ボード・時系列などで押したときも同じく、小窓をそれだけにする（重ねるのは、小窓とページの中の名前を押したとき）

## 7. その場で作る

- **名前を入れる欄はすべて「ない名前なら、その場で作る」**にそろえる（所属・持ち主・いる所・チャートの点の場所や登場・選ぶ窓・家族の「＋」など）
- 作ったときは下にお知らせ「「葛城」を人物として作りました［書く］」。［書く］で、その人物を小窓で開く（自動では開かない。続けて入れている途中をじゃましない）
- **メモで `[[` と打つと候補が出る**：すべての種類から名前で探した候補（種類の印つき）と、ない名前なら「「X」を人物として作る／ロケーション／アイテム／集団／付箋として作る」。選ぶと `[[X]]` が入る（作るものを選んだときは、その種類で作ってから入る）。↑↓・Enter・Esc が使える
- メモの中のまだない名前のリンク（`[[X]]` で X がない）を押したときは、「どの種類で作るか」を選んでから作る（いまは必ず付箋になる）

## 7.5 複数選んでまとめて（2026-10-07 追加の要望）

- 使える所：人物・シナリオ・アイテム・集団の一覧（表・カード・まとまり）と、付箋の一覧
- 選び方：表は一番左のチェック、カードは左上のチェック（カードにマウスを乗せるか、1つでも選んでいると出る）。Shift を押しながら押すと、前に押したものとの間をまとめて選ぶ。表の見出しのチェックで「いま出ているものを全部」
- 1つでも選ぶと、下に帯が出る：「3件を選んでいます」と、できること・「選ぶのをやめる」
  | できること | 使える種類 | 中身 |
  |---|---|---|
  | シナリオに入れる／シナリオから外す | 人物・アイテム・集団・付箋 | シナリオを選ぶ。登場（中身）に入れる・外す |
  | 場所を移す | 人物・アイテム・集団・シナリオ・付箋 | ロケーションを木の形から選ぶ（「場所なし」も） |
  | 所属に入れる | 人物 | 集団を選び、役職を入れる（空でもよい）。もう入っている人は飛ばす |
  | タグを付ける | すべて | タグの名前を入れる（候補つき） |
  | 消す | すべて | 確かめてから消す |
- どれも1回の「元に戻す」で全部戻る。終わったらお知らせ「3人をシナリオ「黄昏の喫茶店」に入れました」
- 別の画面へ移ると、選んでいたものは外れる

## 7.6 いまのシナリオで絞る（2026-10-07 追加の要望）

- **シナリオの中で人物を選ぶ欄は、そのシナリオの登場人物だけを出す**。チャートの点の「登場」がこれにあたる
  - 「ほかから選ぶ」を押すと、世界の全員から選べる。選んだ人は、自動でそのシナリオの登場にも入る（「登場しないのにチャートにいる」ことが起きない）
  - ない名前を入れたときは、いまと同じく人物を作って登場に入れる
  - シナリオの「登場」の欄そのもの（登場人物を足す所）は、いまどおり世界の全員から選ぶ
- **「シナリオで絞る」**：人物・アイテム・集団の一覧（表・カード・まとまり）、家系図、集団の相関図、グラフに「シナリオ：すべて／（シナリオの名前）」を付ける
  - 選ぶと、そのシナリオに出るものだけになる。出るもの＝登場（中身）に入っているもの・チャートの点に付けたもの。集団の相関図は、そのシナリオに出る集団と、登場人物の所属する集団
  - 1か所で選ぶと、ほかの画面でも同じシナリオで絞った状態になる（読み込み直すと「すべて」に戻る）
  - 絞っている間は、上に「シナリオ：黄昏の喫茶店 ×」と「9 / 120人」のように数を出す（絞っていることを忘れないように）
- **検索でいまのシナリオを先に**：シナリオのページを開いているとき、検索の候補で、そのシナリオに出るものを上にまとめ、「このシナリオ」の印を付ける。メモの `[[` の候補も同じ

## 8. 言葉・細かい直し

- 「付箋」は思いつきのメモ（種類「付箋」）だけを指す。人物などをまとめて言うときは「カード」。画面の文字・元に戻すの説明（例：人物を作ったら「人物を追加」）・説明文を直す
- 付箋の一覧の「null」の文字を消す（同じ原因の所もあわせて直す）
- 設定：「Googleドライブ」を一番上、「見た目」をその次、「暦」は「暦のくわしい設定」としてたたむ（押すと開く）、「架空の暦」はその下
- スマホ：下のタブは主な6つと「…」（押すと「ほかの見方」4つが出る）。最近の一覧は検索欄を押したときに出す。小窓はいまと同じく画面いっぱい（「‹」で戻る）。表は横にずらして見る

## 9. データ

- 変わるのは1つだけ：カードに `pic`（絵の画像の id）を足せる。なくてもよい。世界の版は変えない
- 最近開いたもの・一覧の見せ方・ページの見せ方は、この端末だけに覚える（ブラウザの保存。世界ごと）
- シナリオの共有の写しには、入るカードの絵も入れる（読むページの人物に絵が出る）

## 10. 確かめ方

- 単体：まとめての操作（シナリオに入れる・外す、場所、所属は重ならない、タグ、消す）、シナリオに出るもの（登場・チャートの点・相関図の集団）、検索の並び（始まる・含む・欄・最近・このシナリオが先）、画面のアドレスの読み書き（`#/people/<id>/board` など。`#import` は画面とみなさない）、表の値（所属・いる所・持ち主）と並べ替え（空は最後）、まとまり（複数の所属・なし）、最近の一覧（重ならない・10件まで・新しい順）、`[[` の打ちかけを見つける（`[[` の後ろ、`]]` の前、改行をまたがない）
- ブラウザ（パソコン）：
  - 人物のページ → ボード → ブラウザの戻る2回で一覧へ。進むでページへ
  - 付箋の画面から検索で人物が出て、Enter でページが開く。Ctrl+K で検索欄へ
  - 最近の一覧に開いた順で出る
  - 人物を押すと情報が出る（ボードではない）。空の長い欄は「＋」にたたまれている
  - 小窓：シナリオのページで登場人物を押す → 小窓 → 所属を押す → 重なる → 道すじで戻る → × で閉じる。左のタブで移ると閉じる
  - メモで `[[葛` → 候補、`[[新しい人` → 人物として作る → 人物ができてリンクが入る
  - 名前の欄で新しい名前 → お知らせの［書く］で小窓に開く
  - 表：100人の世界で並べ替え・まとまり・絵が出る
  - 付箋の画面に「null」がない
  - 複数選ぶ：表で3人を選び（Shift で範囲）、シナリオに入れる → 1回の元に戻すで全部戻る。場所を移す・所属・タグ・消すも
  - チャートの点の登場の候補が、そのシナリオの登場人物だけ。「ほかから選ぶ」で選んだ人がシナリオの登場にも入る
  - シナリオで絞る：人物の表で選ぶ → 家系図でも同じシナリオで絞られている。「×」で戻る
  - シナリオのページで検索すると、そのシナリオの登場人物が上に「このシナリオ」の印つきで出る
- スマホの幅：横にはみ出さない。下のタブの「…」から時系列へ行ける。小窓の「‹」で戻る
- これまでのブラウザの確認（17本）は、新しい作りに合わせて直して、すべて通す

## 11. やらないこと

- 2つ以上を左右に並べる（案 B）は、今回はしない。小窓の道すじで行き来する
- ボード・時系列・グラフ・テンプレートの中身は変えない（置き場所だけ）
- チャートの点の「場所」「アイテム」の候補は絞らない（シナリオの外の場所や物も使うため）
- 時系列の画面の見やすさ（字の重なり・難しい言葉）は今回は直さない（あまり使わないため）。必要になったら別に直す
