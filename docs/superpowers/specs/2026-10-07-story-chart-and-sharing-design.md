# ストーリーチャートとシナリオの共有 — 設計

- 作成：2026-10-07。要望「シナリオの編集でストーリーチャートを作る」「シナリオ単位でほかの人に共有する」「付随して必要そうな機能」と、回答をまとめた
- 回答：チャートは、出来事・情報・探索の考えを点にし、PLの行動で分岐・合流する流れ。並びは自動、手でも動かせる。共有は「URLを開くだけで読める簡単なページ（編集なし）」と「ほかのGMに渡す」。URLはGoogleドライブに置く形

## 1. ストーリーチャート

- シナリオを開いた画面で「チャート／ボード」を切り替える（初めはチャート）
- データ：シナリオのカードの `chart = { nodes: { id: { id, title, body, type, refs: [カードid], pos?, time?, place?, cast?, items? } }, edges: { id: { id, from, to, label } } }`
- 点の種類：出来事・情報・場所・判定・選択・エンディング・メモ（色と印）。初めは出来事
- 矢印のラベルは「PLの行動・条件」。分岐・合流・前へ戻る（輪）を許す
- 作る：「＋ 点」、点の「＋ 次へ」（矢印つきで次の点）、点の「→ つなぐ」→ 相手の点を押す
- 並び：入ってくる矢印のない点を一番上に、上→下の段に並べる（輪になる矢印は段の計算に使わない）。段の中は、上の点の位置の平均で並べ、重ならないよう詰める。手で動かした点は `pos` を持ち、その位置のまま。「自動に戻す」で `pos` を消す
- 点のメニュー：直す（題名・種類・メモ）・カードを結び付ける・出来事として時系列に置く・カードにする（付箋・人物・アイテム・集団・ロケーション）・結び付けを外す・自動の位置に戻す・消す
- 手がかりの一覧：種類が「情報」の点と、そこへ入る矢印（どの点で・どの行動で）。入ってくる矢印がない情報には「どこからもつながっていない」

### 1.1 点の場所・いつ・登場・アイテム（2026-10-07 追加）

- 要望「出来事の場合ロケーションを追加できるように。付随して追加するべき要素も」。どの種類の点にも付けられる
- 場所 `place`：ロケーション1つ。点には道すじ（アーカム › 図書館）を出し、押すとそのロケーションを開く。名前で入れ、候補は道すじ。ない名前なら、そのロケーションを作る（一番上に）。「＋ 次へ」の点は、前の点の場所から始まる
- いつ `time`：自由に書く（例：1日目・夜）。時系列の日時とは別（時系列に置くのは「出来事として時系列に置く」）
- 登場 `cast`（人物・集団）・アイテム `items`：名前を入れて Enter で足す。ない名前なら人物・アイテムを作り、このシナリオの登場に入れる
- 場所ごとの一覧：点を場所の道すじごとにまとめる（場所なしは最後）
- ロケーションの詳しい画面の「ここにあるもの」に「ここで起きること（チャート）」：そこ（中のロケーションも含む）を場所にしている点を「シナリオ › 点」で出し、押すとシナリオを開く
- 「出来事として時系列に置く」で作る出来事は、点の場所を「いる所」にする
- カードを消すと、点の場所・登場・アイテム・結び付けからも外す（ドライブで合わせたときも同じ）
- 並び：段の高さは、その段の一番背の高い点に合わせる（中身の多い点が下の点に重ならない）

## 2. 共有（Googleドライブ）

- シナリオの詳しい画面に「共有」の欄：共有リンクを作る／リンクをコピー／更新（同じURLで中身を今のものに）／共有をやめる（ファイルを消す）。「遊んだ記録も入れる」（初めは入れない）
- 写し（シナリオの包み）：`{ format: 'trpg-scenario', version: 1, title, sharedAt, scenario: id, settings, tracks, calendars, templates, notes, links, images }`
  - 入るカード：シナリオ、中身（出来事・登場・付箋）、チャートの点の場所・登場・アイテム・結び付けたカード、これらの場所（とその上のロケーション）
  - 入るつながり：両端が入っているもの。世界線・架空の暦：入るカードが使うもの（本線はいつも）。テンプレート：すべて
  - 画像：入るカードの本文の画像を、文字（data URL）にして入れる。地図は入れない
- ドライブ：世界のフォルダに「共有-シナリオ名.json」を置き、「リンクを知っている人は読める」にする。`scenario.share = { fileId, at, sessions }`
- URL：`…/share.html#f=ファイルid&k=APIキー`。読むページは API キーでファイルを読む（ログイン不要）
- 読むページ：題名・「〇月〇日の内容」・印刷・自分のアプリに取り込む。欄、メモ、チャート（見るだけ。点の場所・いつ・登場・アイテムも。点を押すとページは動かず、チャートの右〈スマホは下から出る板〉にその点の全部・「このあと」〈矢印の先へ進むボタン〉・「ここに来るまで」が出る。名前を押すとその板の中でカードが読める。全部の点を順に読む欄はたたんでおき、印刷では開く）、場所ごとのシーン（点に場所があるとき）、出来事（時間順・日付）、登場人物（欄・メモ・年齢）、アイテム、集団、場所（道すじ）、遊んだ記録（入っていれば）
- 準備：Google Cloud で API キー（ウェブサイトの制限：`https://bojo2803-rgb.github.io/*`、API の制限：Google Drive API）。設定のGoogleドライブの欄に貼る。手順書に足す

## 3. 取り込み

- 読むページの「自分のアプリに取り込む」→ アプリを `#import=f:ファイルid&k=APIキー` で開く → 確かめて、いま開いている世界に入れる
- 入れ方：カード・つながりは新しい id（相手の世界を上書きしない）。本線は本線に。ほかの世界線・暦は同じ id があればそれ、なければ足す。テンプレートはない id だけ足す。画像はその世界の保存先に置く
- ファイル：シナリオの「共有」の欄の「ファイルに書き出す」。世界の「読み込む」で `trpg-scenario` のファイルを選ぶと、いまの世界に入れる

## 4. 確かめ方

- 単体：チャートの並び（段・分岐・合流・輪で止まる・手で置いた点）、手がかり、写しに入るもの、取り込み（id の付け替え・本線・上書きしない）
- ブラウザ：チャートを作る・つなぐ・ラベル・動かす・自動に戻す・手がかり・時系列に置く。偽物のドライブで共有リンク→読むページ→取り込み、更新・やめる。ファイルで書き出し→読み込み。スマホの幅
